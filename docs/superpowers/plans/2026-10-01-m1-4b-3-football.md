# M1-4b-3: Football fixtures (question 3.2)
m1-4b-3-football · Subagent (/do-task) · Notion: <card id not provided>

## Goal and scope
- **Sync.** `FootballFixturesSync`, a new `CalendarSource`, pulls football-data.org v4 Ligue 1 (`FL1`) and Champions League (`CL`) matches into `reference_calendar`:
  - kind `fixture`, already allowed by V162 `ck_reference_calendar_kind CHECK (kind IN ('holiday','school','pont','dst','hijri','fixture'))`, so there is no migration;
  - country `FR`, region `''`;
  - one batch per competition URL;
  - a scope prefix, so the per-source startup seed (`ReferenceCalendarJob.needsSeed`) fills it on the first boot after it is turned on.
- **Gate (kill switch).** Commercial use of the football-data Free tier is still unconfirmed (pending with Ivan). `FOOTBALL_DATA_API_KEY` is already set on Railway, so the key alone must not turn the source on.
  - A new flag `PREDICTOR_FOOTBALL_ENABLED` (default `false`) plus the key form the source.
  - A new `SourceGates` key `football` requires all of: `PREDICTOR_DATE_CHECK_ENABLED`, `PREDICTOR_CALENDAR_SYNC_ENABLED`, the flag, and a non-blank key.
  - With the gate off: no HTTP call, 3.2 answers `not_checked`/`source_off`, and the `sources.yaml` entry is hidden.
- **Which matches count (decision, see OPEN_QUESTIONS in the hand-off):**
  - a `FL1` match where the city's own club plays, home or away (`FootballClubs` map: cityKey → football-data team ids);
  - a `CL` match with a French club, for every FR city. Only CL matches involving a FL1 club are stored.
  - A league match between two other clubs is not a "big match" for this city: clear.
- **Kickoff vs event hours (the 3.2 risk/opportunity split confirmed in the M1-4b Decisions, refined so a far-off match is not a fact):**
  - **RISK:** the match window `[kickoff, kickoff+120 min]` overlaps the event `[start, end]`, or the kickoff is unknown (`TBC`), or `startHour` is null.
  - **OPPORTUNITY** ("you could screen it"): the match ends within 3 h before doors.
  - **Not counted:** the match ends more than 3 h before doors (afternoon match), or starts after the event ends.
  - Strength 3 for CL, 2 for FL1. RISK wins over OPPORTUNITY.
- `CalendarEvaluator.NO_SOURCE_YET` becomes `{5.1, 10.3}`, and 3.2 joins the real rules.
- **Out of scope:**
  - NL/DE/ES leagues (3.2 stays `no_source` there);
  - France national team (WC/EC);
  - imin-public `usedFor` label and PUBLIC_PAGE_API §28 (follow-up, needed before the flag flips);
  - webapp `templateFacts`/timeline follow-up;
  - Stage-0 predictor.
